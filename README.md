# SANCTUARY BAND — support

Customer support site for SANCTUARY BAND: firmware updater and band readout.

The pages are **password protected**: every page in this repository is
encrypted (AES-256-GCM, key derived from the access password with
PBKDF2-SHA256), so neither the pages nor the firmware can be read without the
password. Customers receive the password from us.

Requires Google Chrome or Microsoft Edge on a computer (Web Serial).
